O que o PLUTOS faz com isso {% if cn.chave == 'shopee' %}

Do ORDER.ALL (1 linha por item): junta em 1 por pedido, tira os cancelados; comissão do sistema = % × subtotal + R$/item × quantidade (Parâmetros: Shopee 12% + R$ 12); comissão real = comissão bruta + serviço bruta − ajuste por ação comercial; a diferença é o rebate de comissão.

Rebate em R$ = Incentivo Shopee para ação comercial + Incentivo de cupom. Rebate em frete = frete estimado − frete pago pelo comprador (Frete Grátis, teto R$ 40). Chave: ID do pedido = OC do ERP. Pode subir o mês de novo: o pedido é atualizado, nunca somado.

{% elif cn.chave == 'magalu' %}

Do FINANCEIRO POR PERÍODO: tira os cancelados e a linha de total; comissão do sistema = % + R$/pedido da tabela de Parâmetros (Magalu 11% + R$ 5) sobre o valor pago pelo cliente; comissão real = Serviços do marketplace (1+2+3+4) + Tarifa fixa; a diferença é o rebate de comissão.

Rebate em R$ = coparticipação de descontos paga pelo Magalu (desconto à vista + preço promocional) + subsídio de cupom pago pelo Magalu. Coparticipação de frete vai para a conta logística, não é rebate. OC do ERP casa tirando o sufixo "-1/-2".

{% else %}

Da TABELA GERAL: separa por mês da data do pedido, calcula o % de comissão cobrada, marca os pedidos de tarifa zero (vão para a tabela Faltante campanha) e soma o Cupom Meli como rebate em R$.

Do RESUMO DE REBATES (Planilha 2): monta a Lista de MLB's — cada anúncio com SKU e tipo (Premium 16,5% · Clássico 11,5%); sobe quantas vezes quiser, o MLB que já existe é atualizado, nunca duplicado.

Da comissão do sistema (box 0 · ERP): casa cada pedido pela OC = "Pedido Marketplace (Any)", aplica o % do ERP (coluna AB) sobre o valor de produtos do export e calcula a diferença comissão do sistema − tarifa cobrada = rebate de comissão.

{% endif %}
